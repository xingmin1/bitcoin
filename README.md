比特币网络的运行：采用多线程程序设计模拟；只考虑全节点，每一个节点为一个线程；节点可以创建交易、发布交易、验证交易和挖矿；最终依据最长链原则更新节点上的区块链。注：节点数量大于4就可以了，取4~8之间。

每个线程的任务{
    随机睡眠一点时间

    创建自己的钱包

    loop {
        确保在最长链上

        如果没有区块链，则用自己的地址创建区块链

        随机转账，并广播

        如果待处理的合法交易是否不少于n个
            循环、阻塞获取交易
            
        确保在最长链上
        如果区块链不是原来的区块链，则continue（跳过下面的挖矿，直接进入下一轮）

        挖矿，并广播
    } 循环一定轮次
    
}

    发送 获取版本 消息

    「
        接受消息，并处理

    」 在其中持续一段时间，类似睡眠，但可以处理消息
」

处理消息{
    版本消息 -》 对比链长度，如果小于，则发送获取区块消息，阻塞等待区块消息，然后递归处理
    区块消息 -》 先验证区块，再验证区块中的交易，如果合法，则将该区块加入到区块缓存中，「
        如果该区块的前一个区块是本线程区块链的tip，则将该区块缓存加入到区块链中，并更新tip
        如果该区块的前一个区块不是本线程区块链的tip，则继续请求获取该区块的父区块，阻塞等待父区块消息，然后递归处理
    」
    交易消息 -》 验证交易，如果合法，则将该交易加入到交易缓存中

    获取区块消息 -》 在区块链中找到该区块，并发送该区块
    获取交易消息 -》 在交易缓存中找到该交易，并发送该交易
    获取版本消息 -》 将本线程区块链的版本号发送
}

每个线程的资源{
    区块链
    交易缓存
    区块缓存
    钱包
