# Rust Bitcoin Simulator

这是一个使用 Rust 实现的简化的类比特币区块链网络模拟器。该项目旨在演示区块链的核心概念，包括交易、区块、工作量证明（Proof-of-Work）挖矿、点对点网络以及钱包管理。网络中的每个节点都在独立的线程中运行，以模拟一个去中心化的环境。

## ✨ 功能特性

*   **区块链**: 使用 `RocksDB` 作为存储后端，实现了持久化的区块链。
*   **工作量证明 (PoW)**: 采用简单的 PoW 共识算法来保障网络安全。
*   **P2P 网络模拟**: 模拟了一个全连接的节点网络，每个节点都在一个独立的线程中运行。
*   **交易**: 基于 UTXO 模型的交易，使用 `secp256k1` 进行 ECDSA 签名和验证。
*   **UTXO 集**: 为 UTXO 集使用独立的 `RocksDB` 数据库，以实现高效的余额查询和交易创建。
*   **钱包**: 支持钱包创建和管理，包含公私钥对和 Base58 编码的地址。
*   **内存池 (Mempool)**: 每个节点都拥有一个内存池，用于暂存待确认的交易。
*   **默克尔树 (Merkle Tree)**: 用于哈希区块内的所有交易，确保数据的完整性。
*   **命令行界面 (CLI)**: 提供一个用户友好的 CLI 与网络进行交互，并支持交互模式。

## 🚀 如何构建和运行

### 先决条件
*   Rust and Cargo: [安装 Rust](https://www.rust-lang.org/tools/install)

### 1. 构建项目
```bash
cargo build --release
```

### 2. 运行程序
本应用提供了一个 CLI 来管理模拟过程。

*   **初始化区块链:**
    此命令会清理所有旧数据，并为每个节点创建新的钱包和数据目录。
    ```bash
    cargo run --release -- init
    ```

*   **运行自动模拟:**
    此命令将启动网络模拟，节点会自动创建交易并进行预设轮次的挖矿。
    ```bash
    cargo run --release -- auto-run
    ```

*   **运行交互模式:**
    此命令会启动模拟，并提供一个交互式命令行用于手动控制。
    ```bash
    cargo run --release -- auto-run -- --is-interactive
    ```

*   **清理数据:**
    此命令会删除所有的区块链和钱包数据。
    ```bash
    cargo run --release -- clean
    ```

## 🎮 交互模式用法

在交互模式下，您可以使用以下命令：

*   `help`: 显示可用的命令。
*   `send -f <from_node_id> -t <to_node_id> -a <amount>`: 从一个节点向另一个节点发送指定数量的代币。
*   `balance -n <node_id>`: 查询指定节点的余额。
*   `chain -n <node_id>`: 打印指定节点的区块链信息。
*   `wallets -n <node_id>`: 列出指定节点的钱包地址。
*   `verify -n <node_id>`: 验证指定节点区块链的完整性。
*   `continue`: 让模拟继续运行一轮。
*   `exit`: 退出交互模式。
